# Требования

Система хранит номер договора и название контрагента. Договор может содержать несколько обязательств с отдельным идентификатором, описанием, ответственным и датой исполнения. Пользователь может добавить договор, зарегистрировать обязательство, отметить его выполненным и просмотреть отчёт по состоянию на выбранную дату.

Открытое обязательство просрочено, если его срок раньше даты отчёта. Если даты совпадают, в отчёте отражается «Срок сегодня». Выполнение фиксируется отдельно. При повторном закрытии действие отклоняется.

Критерии приёмки: реестр сохраняется после закрытия программы, дубликат номера договора отклоняется, статусы до срока, в день срока и после срока различаются, закрытые позиции показаны отдельно.
